# BetterIcon app icons

Original artwork by **OmegaDarling**, supplied for BetterIcon. These are the approved, unmodified sources: Clay, Copper, Mauve, Ochre, Sage, Slate, Stone, and Teal, each in Dark and Light. The 16 larger originals and 16 corresponding `32px/` images are retained byte for byte.

`betterIcon_icon_sage_dark.png` is the executable's default icon. The local Windows build embeds all 16 choices as multi-size ICOs: 16/24/32px frames use the dedicated `32px/` artwork; 48/64/128/256px frames use the larger originals. The tray loads the small frame explicitly. No other artwork pack is used for BetterIcon's own identity.

Settings > Appearance selects the color and either matches the current app appearance or pins the Dark/Light variant. Fresh preferences use System, Sage, and Match appearance. These choices change BetterIcon's window and tray icon; ArtCraft shortcut packs are managed separately.
