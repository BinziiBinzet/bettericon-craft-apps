# BetterIcon for Linux

BetterIcon 1.29.1 launches installed ArtCraft desktop apps and manages their icons from the **Launcher** and **Manage Icons** tabs. The package carries the list of 41 packs and a small preview of each. A pack downloads when you click its name or press Enter. After an upgrade from an edition that carried every pack, BetterIcon downloads the packs you had chosen again at the first start, so both pickers open as you left them. Without a connection it keeps your choices and tries again at the next start or pack refresh. The package includes catalog helpers for ARM64 and x86-64. Installing removes the folders of earlier BetterIcon versions. Starting in the tray loads the window interface only when you first open it. The interface uses software rendering.

On a new installation the window offers once, under the tabs, to download all app icon packs, all file type icon packs, or both, each with its count and download size. In a small Launcher window the offer takes one line, and **Download icon packs…** shows the whole choice in **Manage Icons**. **Not now** leaves every pack to download when you choose it. Nothing is modal: the packs download one after another while you keep using BetterIcon, and the place of the offer and the status line under the buttons in **Manage Icons**, beside any other news, show the progress. Refreshing the list, choosing a pack, importing, saving and applying start at once while a pack downloads, and a pack you choose while the offer fetches it downloads only once. At the end they say how many packs downloaded and name, by cause, up to three packs that could not be downloaded; the others still download, and such a pack downloads when you choose it. When GitHub cannot be reached at all, the downloads stop at once with one sentence that says so. The outcome stays until you close it. If you quit while the packs download, the rest download at the next start. An upgraded installation never sees the offer, also one from a version that never saved a preference: the installer notes that it replaced an earlier installation. The download sizes come from `macOS/PackSizes.tsv`, which `macOS/pack-sizes.py` writes from the pack artwork for the catalog the package carries.

VimiummuimiV’s eight Modern Flat variants appear as one 13-icon pack. BetterIcon remembers the app icon pack and the file type icon pack separately. If your downloaded artwork differs, it stays usable offline and shows **Update available** until you select the pack.

## Install

Extract the Linux archive, open its folder in a terminal, and run:

```sh
./install.sh
```

The installer creates a per-user virtual environment, adds **BetterIcon for ArtCraft** to Applications, and starts its tray icon. BetterIcon starts in the tray when you log in. It uses the system Python 3.11 or newer, PyGObject, GTK 3, WebKitGTK 4.1 and X11 or XWayland. Ubuntu 24.04 provides the dependencies as `python3-venv python3-gi gir1.2-gtk-3.0 gir1.2-webkit2-4.1`. WebP artwork needs no extra package: BetterIcon decodes it with the system libwebp, which WebKitGTK already requires, or else with a GdkPixbuf WebP loader. The installer warns if neither can be loaded. GNOME displays the tray icon through Ubuntu AppIndicators or the equivalent tray extension. On an X11 desktop use a panel with a system tray.

On some NVIDIA machines running Ubuntu 24.04, a headless GNOME Remote Login session can close when an X11 app opens a window. On affected machines, configure the remote GNOME Shell session to start XWayland with `XWAYLAND_NO_GLAMOR=1` so it uses shared memory. The XWayland server inherits this setting when GNOME starts. [Ubuntu Mutter report](https://bugs.launchpad.net/bugs/2164959) · [Ubuntu XWayland manual](https://manpages.ubuntu.com/manpages/noble/man1/Xwayland.1.html)

## Launcher and icons

- Click an app once to open it. Hovering or choosing it with the arrow keys lightens its icon. While you hold the mouse button, the icon is slightly smaller and darker. Press **Enter** to open the keyboard selection.
- The default shortcut is **Ctrl+Alt+A**. It opens Launcher at the pointer. Click the shortcut text at the lower left to change or disable it. GNOME registers the binding with the compositor. Other X11 desktops use an X11 key grab. Other Wayland desktops can assign `bettericon --launcher` in the desktop shortcut settings.
- Click the tray icon to open the larger tab by saved window area. Launcher opens on a tie. A second click hides the popup. Drag the diagonal grip just inside the lower-right corner, or drag an edge, to size each tab independently. Launcher can shrink to 300 × 240 and Manage Icons to 790 × 570 when the screen allows. Switching tabs keeps the divider at its screen position.
- Pick an **App icon pack** in **Manage Icons**. Manage Icons previews it. The Launcher changes to a pack when you apply it, and then shows that pack’s icons. After you update the applied pack, the Launcher shows the updated artwork; the desktop entries keep the earlier artwork until you choose **Apply icons…** again. Choose **Apply icons…** to review the desktop entries that will change. System-wide launchers receive a per-user override, and a file type such an app shares with another app keeps the default app the system chose for it. **Restore app defaults…** restores the original user files and removes overrides BetterIcon created. Externally edited entries are marked during review.
- BetterIcon keeps its app entries in step with app updates. When a package update changes an app’s desktop entry, BetterIcon’s override follows the new entry and keeps the pack’s icon, and when an app is removed its override goes too. When the ArtCraft Launcher rewrites an AppImage app’s entry during an update, BetterIcon puts the pack’s icon back, and **Restore app defaults…** then restores the updated entry. BetterIcon watches the applications folders, also checks when it starts and whenever half an hour passes without a check, and says in the status line what it brought up to date. Entries you edit yourself are left alone, also when you give an app an icon of your own, and while the original icons are applied BetterIcon leaves an updated entry as the update wrote it. A themed launcher on the desktop or in an added folder that is away for a while, in the Trash or on a drive that is not mounted, keeps its backup, and **Restore app defaults…** puts the original back once it is there again.
- Newly installed ArtCraft apps get the applied pack. An app installed after you applied an icon pack gets the pack’s icon at the next check, the same way **Apply icons…** would give it, and **Restore app defaults…** takes it back like the others. So does a launcher you put on the desktop, or a new entry in a folder you added; the entries a folder holds when you add it change only through **Apply icons…**. Apps the pack has no icon for and entries you restored on their own keep their icons, and nothing changes while the original icons are applied. The status line names the apps and entries that were given the pack. After an update of the applied pack, a newly installed app gets the updated artwork, while apps that already had the pack keep the earlier artwork until the next Apply.
- **Launcher icon size** and **Show app names** set how the Launcher and the previews draw their icons.
- Right-click the tray icon to refresh installed apps, include an additional folder of desktop entries, or exit. The Launcher uses the distribution's desktop entry to start each installed app. An empty Launcher means there are no matching ArtCraft desktop entries in the scanned locations.
- Hover an item in either pack menu to preview up to three icons. A pack with ArtCraft Launcher artwork shows it first, and the file type menu previews the pack’s file icons. Packs are listed by author, then by name, and ArtCraft Launcher leads the Launcher and each pack’s icons. The menu shows whether a pack is downloaded, or available for download or update. Click **Refresh available icon packs** at the right of the two pack pickers or choose the same action from the tray menu.
- BetterIcon checks for new or updated packs at startup and about every 30 minutes. A dot appears on the refresh button when it finds changes. Refresh the list to see the changes, then select any pack you want to download or update.
- **File type icon pack** sits beside **App icon pack**. It lists the packs that draw file icons: Komplett’s five document packs, Mike22’s three CraftApps AIO November sets, and personal packs with file artwork. The chosen file type pack previews next to the app pack. BetterIcon knows 37 file designs, such as .pcraft, .psd, and .pdf. A pack can draw one design for a format (`FileTypes/pcraft.png`) or one for everything an app opens (`FileTypes/PhotoCraft-PSD.png`).
- WebP artwork is accepted, preferred over a PNG of the same icon, and kept as PNG. Animated WebP is not accepted. Name a WebP like a PNG: `PhotoCraft.webp`, `FileTypes/pcraft.webp`, `FileTypes/PhotoCraft-PSD.webp`; BetterIcon 1.27 and earlier show only the PNG, so packs should keep a PNG with the same name beside each WebP. A WebP must be a still image of at most 4096 pixels per side and 16 MB. A WebP that cannot be used (damaged, animated, too large, not really WebP, or no decoder on this computer) gives way to the next format of the same icon, normally its PNG twin; an icon with no usable file is left out, and the status line names it with the cause when you choose the pack, as in “App icon pack selected. Left out: PhotoCraft. Animated WebP artwork is not supported.” From 1.29.0 a published pack downloads one file per icon: the WebP where this computer can decode WebP and the PNG otherwise, and the pack's PNG files as well when one of its downloaded WebP files turns out unusable. From 1.29.1 an update takes every file an earlier download of the pack still holds unchanged from this computer, fetches only the rest, and then removes the earlier download; shortly after each start BetterIcon also removes copies that updates with earlier versions left behind. When you choose a pack, and at start for the chosen and applied packs, its WebP files are decoded in full in the background. **Apply icons…** converts your installed apps’ WebP icons in the background before its review, however the pack came to this computer, and keeps PNG copies only for the entries it changes; **Apply file icons…** converts while it shows that it is applying. Applied icons and file icons are PNG copies named by the WebP file’s own checksum. Imports try each icon’s files in the order WebP, PNG, SVG, ICO, ICNS, JPEG and keep the first that converts; if none does, the import stops with the icon and the cause, for example “PhotoCraft: The WebP file is damaged or incomplete.” Exports contain PNG, so BetterIcon for Windows and the Mac, also older versions, read them.
- File types outside BetterIcon’s list of 37 designs: art published as `FileTypes/<App>-files.png` (or `.webp`, `.svg`, `.ico`) also themes the file types that app opens by default and that no listed format uses. The name must be the app’s name, exactly one space, underscore, dot or hyphen, then `files` in any case, such as `TextureCraft-files.png` or `ArtCraft Launcher_files.webp`. Art named for a format, such as Mike22’s `FileTypes/PhotoCraft-PSD.png`, or Komplett’s app icons, keeps its earlier behaviour: it draws only that app’s listed formats. When an app’s art comes in several files, every one must be named so. Such a type is themed only while that ArtCraft app is its default application and the file type pack you applied has that app’s art. When its default moves to another app, or while the app’s desktop entry is gone, as during a reinstall, the next check takes the icon away, and a later check gives it back once that ArtCraft app is its default again; the status line says when a check does either. BetterIcon checks when a list of default applications changes, as when you choose another app in Files, GNOME Settings or with `xdg-mime`, and when it starts and every half hour. Manage Icons counts such art in the file type pack’s line, as in “2 file types, plus other TextureCraft files”, or “Other LightCraft files” for an app without listed formats, and **Apply file icons…** applies it. Candidates are the MIME types the ArtCraft apps’ desktop entries declare, or that a list of default applications gives them, that no listed format uses (neither the type BetterIcon gives a native format nor the type of a listed extension or alias), that are not generic (such as `text/plain` or `application/octet-stream`) or `inode/*`, that no glob of a listed extension gives, and that a file name pattern or a content rule of the MIME database can give a file. Listed formats keep their own rules: an ArtCraft format always shows its design, a common format changes only while an ArtCraft app is its default application, a format’s own design comes first and that app’s art for all its files second, and the catch-all never takes a type a listed format uses. BetterIcon never changes default apps, `mimeapps.list` or desktop entries for these types, and registers no file name patterns or types for them. A MIME type’s icon covers every file of that type in your account, so the **Apply file icons…** review lists each such type with all its file name patterns, adding “or by content” when the MIME database also recognizes its files by their content, as does BetterIcon’s record; file managers may still show thumbnails instead of the icon. When a default app or a type’s file name patterns change while the review is open, Apply changes nothing and shows the review again with what would change now. If BetterIcon’s data folder is deleted, the next check takes these types back from their registration, with their default-app rule, and **Restore file icons…** names them. A personal pack keeps such art from its folder or ZIP import as its own item, beside filling in that app’s listed formats that have no design of their own; editing the pack keeps it, and the export writes it as `FileTypes/<App>-files.png`, so a reimport keeps it too. Packs saved by earlier versions do not have it, so they never start theming these types after an upgrade.
- **Apply file icons…** gives file types the pack’s icons in your account. BetterIcon registers each icon for its file type and puts a copy into your icon themes, so Files and file dialogs show it with every icon theme installed on the computer, in light and dark styles. It checks these copies when it starts and whenever you change the icon theme. An ArtCraft format such as .pcraft always changes. A common format such as PNG or PDF changes only while an ArtCraft app is its default application: when its default moves to another app, or while that app’s desktop entry is gone, the next check takes the pack’s icon away, and a later check gives it back once that ArtCraft app is its default again (file icons applied before this version keep theirs until the next Apply). When an app you install later brings file types the applied file type pack has designs for, such as its own type for a format or a common format it opens by default, the next check gives them the pack’s icons too. Files keeps showing previews instead of icons for pictures and other files it can preview. The review lists the designs that change, the ones left alone and the file types Files previews. In a Files window that is already open, press F5 to see the change. **Restore file icons…** removes the registration and every icon copy BetterIcon made, and file types waiting for their ArtCraft app to open them by default again no longer get the pack’s icon back. With **Original file icons** chosen, the one action is **Restore original file icons…**.
- Right-click either pack selector to customize, edit, or export a pack. **Remove app pack** and **Remove file pack** remove the pack chosen in each list. Right-click the app pack selector to restore hidden built-in packs. Import a BetterIcon ZIP or an artwork folder to make a personal pack. The version text opens the GitHub project. Removing a file pack keeps the file icons you applied; **Restore original file icons…** removes them.
- The buttons beside the version text choose BetterIcon’s own icon and cycle Dark, Light, and System appearance. The app takes its colors from the chosen icon. From 1.29.1 its scroll bars do too: they are drawn in those colors, with a thumb that changes under the pointer and while you drag it, and stay visible while a list or page is longer than its area. There are twenty choices: ten styles, including Grayscale and High contrast, each in Dark and Light. Choosing a named Dark or Light icon also switches the appearance. **Match app theme** follows the appearance button.

To uninstall the app, use `./uninstall.sh` from the extracted package. The installed copy also provides `python3 "${XDG_DATA_HOME:-$HOME/.local/share}/bettericon-desktop/uninstall.py" --uninstall`. Restore themed entries and file icons in Manage Icons first if you want to revert them. File icons you leave applied keep working with the icon themes installed at that time, and BetterIcon’s registration of their file types stays in your account with them. App icons you leave applied keep the pack’s icons but no longer follow app updates, so a package update can leave an app’s menu entry out of date; choose **Restore app defaults…** before uninstalling to avoid that. Personal packs, backups and preferences stay in your account.

## Build from source

With Go 1.25 on PATH, build locally using Python 3.11 or newer. From a project-specific virtual environment run `python Linux/build-desktop.py /path/to/output`. The build takes the catalog, the app icons and the hover strips from the checkout, verifies them against their manifests, packages no pack artwork, and emits an archive and SHA-256 checksum. It also packages `macOS/PackSizes.tsv`, and warns when that table was written for another catalog; run `python3 macOS/pack-sizes.py` on a checkout with the pack artwork after `Windows/PackCatalog.tsv` changes. The app’s color schemes come from `Shared/themes.json`, which `Windows/Export-Themes.ps1` writes from the Windows app. In a source checkout, `Linux/install.sh` and `Linux/uninstall.sh` remain the legacy terminal icon installation and restore tools.

Run `bash Linux/test-desktop.sh /path/to/extracted-package` for the X11 desktop suite. On a machine with Mutter and XWayland, add `--mutter-resize` to exercise pointer drags in GNOME’s compositor using a private virtual display. Both modes use a temporary user profile. The file icon checks look icons up with GTK 3 and GTK 4 and need gir1.2-gtk-4.0.
