# circleb icon packs

The app-named PNGs at this folder's root are the existing circleb theme.

## Origami Animals

![Origami Animals preview](Origami%20Animals%20Preview.png)

[Download the BetterIcon pack](circleb%20-%20Origami%20Animals.zip) · [Original Discord post](https://discord.com/channels/1359579021108842617/1558575189170585631/1569409332389482542)

The ten PNGs in this ZIP retain the source bytes. The new style is supplied as a ZIP so the Linux installer continues to offer the existing root theme. Import the ZIP through BetterIcon's Manage Icons menu.
