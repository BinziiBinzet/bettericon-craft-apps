# Modern Flat by VimiummuimiV

[Modern Flat](Modern%20Flat/) contains 13 app icons. Select **Modern Flat / VimiummuimiV** in BetterIcon or import the folder into Manage Icons.

Eleven apps used identical artwork across the eight original combinations. SoundCraft uses **Knob**, the more recently modified design in the creator’s SVG archive. For EffectCraft, **Bolt**, **Spark**, and **Wand** share the newest modification time. **Wand** had the latest creation timestamp of the three.

The pack uses transparent PNGs rendered from the creator’s SVGs. The original archive includes every alternate design. The file-type artwork was posted separately.
