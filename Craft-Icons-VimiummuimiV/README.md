Modern Flat has four EffectCraft choices (Bolt, Sliders, Spark, Wand) and two SoundCraft choices (Knob, Sliders). All eight combinations are provided. Bolt + Knob is the main combination in the creator preview. The original SVG bundle is preserved in `Modern Flat - original SVGs.zip`. Its SVGs were rendered to transparent PNGs because the BetterIcon 1.23.1 SVG renderer changes their appearance. [File Type Icons - original.zip](File%20Type%20Icons%20-%20original.zip) preserves the separate [file-type icon post](https://discord.com/channels/1359579021108842617/1558575189170585631/1565594911397515294); BetterIcon 1.23.1 does not install file-type associations.
